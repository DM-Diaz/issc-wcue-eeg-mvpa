# ISSC wCue EEG/MVPA

EEG preprocessing, ERP, and multivariate decoding code for the ISSC wCue reward and task-switching project.

This repository contains the MATLAB/EEGLAB preprocessing pipeline, Python/MNE decoding analyses, bin descriptor files, compact analysis outputs, and supplemental project materials.

For the full description of the experimental design, EEG preprocessing, EEG–behavior alignment, decoding procedures, statistical analyses, file structure, and reproducibility workflow, see:

**`ISSC_wCue_EEG_Methods_and_Analysis_DM_Diaz_YC_Chiu_2026.pdf`**

Large per-subject prediction outputs generated by the decoding scripts are not stored in this repository because of their size.
