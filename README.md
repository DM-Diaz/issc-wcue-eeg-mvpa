# ISSC wCue EEG/MVPA

EEG preprocessing, ERP, and multivariate decoding code for the ISSC wCue reward and task-switching project.

This repository contains the MATLAB/EEGLAB preprocessing pipeline, Python/MNE decoding analyses, bin descriptor files, compact analysis outputs, and supplemental project materials.

For the full description of the experimental design, EEG preprocessing, EEG–behavior alignment, decoding procedures, statistical analyses, file structure, and reproducibility workflow, see:

**`ISSC_wCue_EEG_Methods_and_Analysis_DM_Diaz_YC_Chiu_2026.pdf`**

# Data Availability

Raw participant-level EEG recordings, original behavioral source files, and other source data are not included in this repository. The repository contains analysis code and selected derived outputs only.

Compact per-subject decoding score arrays are included where useful for reproducing reported analyses and figures. Larger per-subject prediction and decision-score files generated by the decoding scripts are not stored in GitHub because of their size.

The analysis scripts are written to operate on the original study data when those files are available in the expected local directory structure.
