marker code

1 = lowSR (low switch reward)
2 = noR (no reward at all)
3 = highSR (high switch reward)

4 = switch-to-animacy task
5 = switch-to-size task
6 = repeat-animacy task
7 = repeat-size task

8 = voluntary task cue

13 = 'c'
14 = 'm'
15 = 'd'
16 = 'k'
17 = other than those

10 = feedback onset, incorrect
11 = feedback onset, correct
12 = feedback onset, too slow/no response

9 = beginning of each block


python command: 
a=10
print(bytes([a]))
bytes([a])==bytes([int('0x0A', 16)])

or if a='4'
print(bytes([int(a)]))
bytes([int(a)])==bytes([int('0x04', 16)])
